# Telega Desktop 1.0.3 x64 RELEASE

## Что изменилось с 1.0.2

### Настройки и навигация

- Вернули один пункт «Настройки Telega macOS» и страницу с поиском и семью карточками. Оформление, темы и фон, сообщения, перевод, приватность, сеть и обновления открываются в обычных настройках.
- ИИ-чат открывается в правой области окна. Слева остаются настройки, и кнопка «Назад» возвращает к предыдущей странице. «Мой профиль» также открывается справа с сохранением панели настроек.

### Интерфейс чатов

- Обновили шапку чата в стиле macOS. Имя, статус, фото, звонок и другие действия размещены на плавающих панелях с Liquid Glass. Для панели бизнес-бота применён тот же эффект.
- Привели скругление обычных и видеоаватаров к общей настройке в списках чатов, сообщениях, профилях, звонках и верхних панелях. Режим скруглённых квадратов ограничивает радиус всех аватаров, а единое скругление применяет выбранный радиус и к форумам. В настройках есть предпросмотр и предложение перезапустить клиент.

### Оформление

- В «Оформлении» появились живые обои. Можно выбрать локальное видео до 60 секунд, посмотреть его перед применением и вернуться к статичному фону. Видео воспроизводится без звука и приостанавливается при уходе приложения в фон.
- К встроенным иконкам добавили загрузку своей иконки с предпросмотром. Она сохраняется локально. После перезапуска выбранная иконка используется в окне, трее и ярлыке.

### ИИ-чат

- К Gemini добавили OpenAI, Claude и Perplexity. У каждого сервиса свой API-ключ, выбор модели и отдельная локальная история. Температура доступна для поддерживаемых сервисов.
- Из шапки чата можно открыть настройки и очистить историю текущего сервиса. Ответы, статусы и ошибки подписаны названием выбранного сервиса.

### Приватность

- Добавили локальное сохранение удалённых сообщений и истории правок. Можно включить сохранение в чатах с ботами, выбрать отметку удалённого сообщения, включить полупрозрачность и посмотреть результат в настройках.
- Сохранённые версии доступны через «История изменений» в меню сообщения. Архив можно очистить отдельно для каждого аккаунта. Сохранение применяется к подходящим сообщениям, которые клиент уже получил.

### Windows и обновления

- В свойствах приложения, установщике и интерфейсе версия отображается с пометкой RELEASE.
- Установщик для Windows x64 и подписанный пакет автообновления опубликованы вместе с SHA-256. Клиенты 1.0.2 могут скачать 1.0.3 с GitHub проекта. Выбор автоматического запуска Tg Ws Proxy доступен при установке.
- Исходники включают Windows-патчи для регистрации ссылок Telega, статической сборки Qt и WebView2. Инструкция по применению находится в README.

Проверены сборка Release, запуск с отдельным профилем, тестовая установка и удаление, обновление значка ярлыка, регистрация ссылок и опция Tg Ws Proxy. Внешний вид в авторизованном клиенте и переход с 1.0.2 через встроенный апдейтер остаются отдельными проверками.
