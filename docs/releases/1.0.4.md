## Что изменилось с 1.0.3

### Стили интерфейса и навигация

- В «Настройки Telega Desktop → Оформление» появилась строка «Выбор стиля» с пометкой «бета». Доступны macOS (по умолчанию), Telegram, Material Design 3 и Unigram. Стиль применяется после перезапуска.
- Telegram включает классическое оформление Telegram Desktop. Эффекты Liquid Glass и настройка стороны кнопок окна доступны в стиле macOS.
- Material Design 3 добавляет скруглённые выделения чатов и меню, плавающее поле ввода, сгруппированные настройки и оформление переключателей и ползунков. Пункт «Настройки Material Design 3» виден только при выборе этого стиля. В нём можно настроить эти элементы, шрифт и анимации Material Expressive.
- Unigram добавляет светлую и тёмную палитры Fluent, Segoe UI Variable при наличии, узорчатые обои, компактное меню и плавающие элементы чата. В широком окне список настроек остаётся слева, раздел открывается справа. Обновлены экран облачного пароля и предпросмотр уведомлений.
- При переключении папок список чатов смещается в сторону выбранной папки. Material Expressive добавляет затухание, а в стиле Unigram акцентная полоска плавно перемещается между папками на боковой панели.

### Оформление, профиль и приватность

- Google Sans добавлен в список шрифтов. Выбор шрифта вынесен в отдельную группу. Повторяющийся пункт «Темы и фон» убран из стандартного оформления, отдельная плитка находится в настройках Telega Desktop.
- В предпросмотре размера стикеров отображается пример стикера. Он меняет размер при перемещении ползунка. Предпросмотр учитывает режим отображения времени и настройку секунд.
- Правый клик по карточке профиля и пункту «Мой профиль» больше не открывает главное меню.
- При включённом локальном скрытии номера строка телефона исчезает из профиля и настроек. Показ номера возвращается через настройки приватности Telega Desktop.
- Название «Telega macOS» в настройках заменено на «Telega Desktop». В подсказке об ошибке смены номера используется название Telegram.

### Поддержка проекта

- В настройках Telega Desktop появилась плитка «Поддержать». Она открывает раздел с CloudTips, профилем разработчика `@dev_outside` и каналом `@windows_custom`.
- В разделе есть кнопка для перехода в системные настройки Windows, где можно выбрать Telega Desktop для ссылок `tg:`, `ton:` и `tonsite:`.

### Установка и обновление

- Проведены тестовая установка на русском и английском, запуск установленного клиента, проверка ярлыка, регистрации ссылок, обоих состояний опции Tg Ws Proxy и удаления тестовой установки.
- В локальной сборке установщик теперь создаётся прямо в `out/setup-release`.
- Для ручной установки скачайте `Telega-Desktop-Setup-x64.exe`. Подписанный файл `td-update-win-x64-11000004` предназначен для встроенного обновления. Контрольные суммы находятся в `SHA256SUMS.txt`.
