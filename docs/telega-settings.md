# Telega Desktop settings

Open **Settings → Telega Desktop Settings**. In the macOS sidebar it is under **My Profile**, next to **AI Chat**. The settings page appears beside the sidebar and its search filters the eight category cards. AI Chat opens beside the same sidebar. Its header has AI settings and a button to clear the selected provider’s history. The layout and initial Gemini workflow are adapted from GPL-3.0 exDesktop, revision `079ea794fbcb87690a46902196385c2c5f586d14`. [exDesktop source](https://github.com/metawka/exDesktop)

- **Interface style:** under **Appearance → Interface style**, choose **macOS** (default), **Telegram**, **Material Design 3** or **Unigram**. Material Design 3 uses the Windows layout with Google Sans, a rounded chat header, and tinted surfaces. Open **Material Design 3 settings** to preview and configure chat selection, the composer, grouped lists, the side menu, animations, switches and sliders. Style changes apply after restarting. The design follows the [exDesktop Material Design 3 settings](https://github.com/metawka/exDesktop/blob/bb13464ef97636478bb83c07329c8407f0196daa/Telegram/SourceFiles/extera/exd_md3.cpp).
- **Unigram** uses Segoe UI Variable when available, light and dark Fluent palettes, a sliding indicator between folders, and floating chat controls. The design is based on [Unigram](https://github.com/TelegramMessenger/Unigram).
- **Font:** **Appearance → Font** offers the bundled Google Sans alongside the system and installed fonts. Choosing a font restarts the client. With the default font selected, Material Design 3 uses its own font preference.
- **Folder transitions:** switching folders in the sidebar or tab strip slides the list in folder order. Material Expressive adds a short slide with a fade and animates the active folder pill. These transitions follow the app's animation setting.
- **Support:** open CloudTips, the developer profile, or the project’s channel. On Windows, the default-link-client button opens system settings for choosing the handler for `tg:`, `ton:` and `tonsite:` links.
- **Appearance and Themes:** create, import, export and apply local themes. The library is in `tdata/telega-themes`. Adjust wallpaper brightness or select a muted local video of up to 60 seconds under **Appearance → Live wallpaper**. Preview the video before applying it and switch back to a static background at any time. Choose a built-in logo or import a local image, then restart to apply it. Window controls can be placed on either side.
- **AI Chat:** choose Gemini, OpenAI, Claude or Perplexity. Each uses your own API key, a separate local history and provider-specific model settings. The selected service receives the message and context from its own AI chat history. Clear a provider’s history from the chat header. Gemini also handles the optional voice and video transcription features.
- **Messages:** assign left and right double-click actions independently for incoming and outgoing messages. The defaults keep the client's left-click behavior and ordinary right-click menu. A configured right-click gesture briefly delays that menu. Copy, edit, and forward retain the client's restrictions. Quick-forward buttons and colored reply previews can be hidden without removing the menu commands.
- **Translation:** choose the built-in service or opt in to Google Translate. Google receives the text requested for translation, including visible messages when chat translation is active. Protected messages and rich articles in chat-wide translation use the built-in path. Existing eligibility for chat translation still applies. Google is off by default and excluded from backups.
- **Privacy, network and updates:** use Telegram’s security settings, local message retention, proxy and storage settings, and the Telega updater. Windows settings expose the bundled Tg Ws Proxy.
- **Preferences backup:** under Updates, export, import, or reset wallpaper brightness, Gemini preferences, and the stories, messages, and media options listed here. Backups do not contain themes, keys, chat history, account data, or proxy credentials.
- **Other ported preferences:** Appearance can hide the stories strip. Messages can hide bubble tails or the text-copied notification, insert a comma after autocomplete mentions at the start of a message, prefer HD photos and original video, change the video seek step, and pause viewer playback when the app leaves the foreground. Privacy can hide your own phone number locally, move the archive into the main menu, or enable supported system capture protection for the main window. Hiding the local number does not change Telegram privacy rules and capture protection cannot stop all recording methods. Network also opens the native download-folder picker.
- **Liquid Glass:** the native Qt renderer refracts the backdrop around the rim instead of overlaying a stretched top strip. It uses reduced-resolution filtering and reuses filtered backdrops when input pixels and lens parameters are unchanged. The macOS style settings control opacity, blur, refraction and whether supported dialogs use the effect.
- **Profile and display:** show peer IDs, the data center of the available profile photo, or relative last-seen time when Telegram provides an exact timestamp. Choose rounded-square contact avatars in lists that use the default avatar shape. Show seconds and forward counts on messages, use an edit icon or exact view counts, or hide the standard greeting sticker. The same menu also exposes the client’s options for recent stickers, wider messages, bubble rounding and the Telegram compose AI button; it does not turn off Telega AI Chat.
- **Chat list and appearance:** hide the sidebar status badge or the Windows sender thumbnails, and hide All Chats in the vertical or horizontal folder strip when custom folders are available. Hiding that tab does not delete or change any filter on Telegram. Appearance also exposes the native font picker, sticker scale, and sticker timestamp display. Restart for sticker size changes.
- **Message controls:** use the theme accent for sender names, hide inline reactions independently for private chats, groups and channels, count characters as you type, and quote eligible messages automatically when replying without a manual selection. Send As can move to the chat menu. The bottom button for read-only broadcast channels can open a linked discussion or be hidden; channels without a discussion fall back to mute and unmute. Selecting service messages applies only to messages the account can delete.
- **Media and network:** use a custom inline bot for GIF searches and pause voice messages and round video messages independently when the app loses focus. GIF search queries go to the selected bot. Download and upload modes adjust request concurrency and buffering. Faster modes may use more memory and are off by default. Restart to switch modes.
- **Channel feed:** open it from the main menu. Choose visible channels and whether to include the archive, or create local categories. Each account has its own selection. The feed requests up to ten recent posts from each of up to thirty channels per refresh. Activate a preview with Enter or a double click to view the complete post in its normal chat. Marking the current category as read asks for confirmation.
- **Quick actions and polls:** choose and reorder the message hover actions; each action still uses the native eligibility rules. Poll previews only show results the client has already received and is allowed to display.
- **Transcription:** voice and round-video transcription are separate opt-in settings. A transcription button appears beside eligible voice messages in all interface styles. The client asks before sending a recording of up to 8 MiB to Gemini. A round video sends the whole MP4, including its picture and audio. No protected or disappearing messages are sent; the transcript is not added to Gemini chat history.
- **Message menu and calculator:** show an online badge next to sender avatars when Telegram supplies online status. The context menu can hide Copy Photo and local media saving and show selectable message details. Repeat Message resends an eligible message in the same chat or topic without the original sender attribution; it does not override forwarding restrictions or send a paid message. With the compose calculator enabled, type a line like `(2 + 3) * 4=` and press Space to insert `20` without sending the draft.
- **Privacy controls:** optionally leave chats unread when browsing or sending, suppress story view receipts, or stop this client from announcing its online status. Manual mark-as-read and activity on other devices are unchanged. The profile can show authors of already loaded messages, not a hidden member roster. Viewing content can still produce other signals, so these options do not provide anonymity.
- **Local message retention:** enable keeping deleted messages and edit history for messages the client has already received. Choose whether to include bot chats, set the deleted-message mark or translucency, preview the result, and clear stored messages for the account. Open a message’s context menu to view saved revisions.
- **Updates:** choose whether to download updates only or download and install them when restarting Telega. This page also opens the project's GitHub release notes.
- **Bundled Tg Ws Proxy:** Windows users can set its local port, buffer, connection pool, logging, data-center routes, Cloudflare fallback, HTTP/2 and secure transport under Network. Changes apply on restart and preserve the proxy secret and unknown options. The bundled process still listens only on loopback. Changing its port does not change any saved connection in Telega.

## Style menus and streamer mode

In Telegram, Material Design 3 and Unigram, use the current style settings to choose visible sidebar actions. In Unigram, Settings is always available. The macOS settings control Contacts and Calls in bottom navigation, folder tabs in Archive, and Liquid Glass in supported dialogs. Each style stores its own theme, wallpaper and brightness.

Streamer mode appears in Privacy and the side menu. It hides the app’s windows from supported Windows capture tools and suppresses client notifications. The local screen remains readable.

## Scope of the exDesktop port

The settings use Telega's macOS style. Appearance includes system emoji, Telega icon colors, adjustable avatar corners and an option to ignore peer-specific chat themes. Plugins are outside the port. Telega does not use the donor's badge backend, emulate Telegram Premium, or bypass hidden-member restrictions. The bundled proxy does not expose the donor's fake-TLS setting. The channel feed shows previews rather than embedding full interactive chat bubbles.

## Telega Desktop badges

Open **Settings → Telega Desktop Settings → Support → Get a badge**. The request dialog shows the 100 RUB contribution for a sponsor badge, opens CloudTips, and links to **@dev_outside** for sending a payment screenshot. The heart marks a sponsor and the terminal icon marks a developer. The badge appears before the name in the chat list, chat header and profile. Your own badge also appears beside Saved Messages in the list and header. Click a badge in the profile to view its number, owner, type, optional comment and how many users have that type.

The public `poweredoutside/telega-badges` repository stores `badges.json`. Anyone can read the numeric Telegram IDs, badge types, numbers, comments and expiration dates, including older grants in Git history. The owner confirms the recipient's consent before granting a badge. Use the updated client for grants and revocations so it preserves the number, comment and expiration metadata.

Telega loads the list when the chats list opens and refreshes it in the background. It keeps the most recent valid list for offline use. Expired badges disappear from the client and stop counting toward prevalence. Viewing requires no GitHub account or separate sign-in. The developer account can choose **Sponsor**, **Developer**, or **Revoke** in **Support → Manage badges**. Enter a duration in days or leave it empty for a permanent badge. Access is tied to the account's numeric Telegram ID. Use a fine-grained token scoped to the public registry with **Contents: Read and write**. The token stays in memory while the dialog and its requests are active.
