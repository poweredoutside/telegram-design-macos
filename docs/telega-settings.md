# Telega macOS settings

Open **Settings → Telega macOS Settings**. In the macOS sidebar it is under **My Profile**, next to **AI Chat**. The search filters category cards by their titles and setting keywords. AI Chat opens a separate chat pane. Its header contains Gemini settings and the clear-history button. The layout and Gemini workflow are adapted from GPL-3.0 exDesktop, revision `079ea794fbcb87690a46902196385c2c5f586d14`. [exDesktop source](https://github.com/metawka/exDesktop)

- **Appearance:** create a named local theme in the palette editor, import a `.tdesktop-theme` or `.tdesktop-palette`, apply a library theme, and export a copy. The library is in `tdata/telega-themes` under the working profile. The background slider adjusts wallpaper brightness. You can choose the app logo and put the window controls on the left or right. The logo change takes effect after restarting.
- **Gemini:** bring a Google AI Studio key. It is kept only in memory until the app exits. Use **Load models** to see the model catalog available to that key. The separate chat sends only its own submitted messages and the selected context to Google, never Telegram chats. History is shared within the app profile, saved unencrypted in `tdata/telega-ai-chat.json`, and can be cleared in the Gemini page.
- **Messages:** assign left and right double-click actions independently for incoming and outgoing messages. The defaults keep the client's left-click behavior and ordinary right-click menu. A configured right-click gesture briefly delays that menu. Copy, edit, and forward retain the client's restrictions. Quick-forward buttons and colored reply previews can be hidden without removing the menu commands.
- **Translation:** choose the built-in service or opt in to Google Translate. Google receives the text requested for translation, including visible messages when chat translation is active. Protected messages and rich articles in chat-wide translation use the built-in path. Existing eligibility for chat translation still applies. Google is off by default and excluded from backups.
- **Privacy, network, updates, and other:** reuse the client's security and archive controls, proxy and storage settings, existing updater, and system and animation options. On Windows, the bundled Tg Ws Proxy can be set to start on the next client launch; this does not choose a Telegram proxy server for the user.
- **Preferences backup:** under Updates, export, import, or reset wallpaper brightness, Gemini preferences, and the stories, messages, and media options listed here. Backups do not contain themes, keys, chat history, account data, or proxy credentials.
- **Other ported preferences:** Appearance can hide the stories strip. Messages can hide bubble tails or the text-copied notification, insert a comma after autocomplete mentions at the start of a message, prefer HD photos and original video, change the video seek step, and pause viewer playback when the app leaves the foreground. Privacy can mask your own phone number locally, move the archive into the main menu, or enable supported system capture protection for the main window. Masking does not change Telegram privacy rules and capture protection cannot stop all recording methods. Network also opens the native download-folder picker.
- **Liquid Glass:** the native Qt renderer refracts the backdrop around the rim instead of overlaying a stretched top strip. It uses reduced-resolution filtering and reuses filtered backdrops when input pixels and lens parameters are unchanged. The Flutter `liquid_glass_easy` package is a visual reference, not a runtime dependency.
- **Profile and display:** show peer IDs, the data center of the available profile photo, or relative last-seen time when Telegram provides an exact timestamp. Choose rounded-square contact avatars in lists that use the default avatar shape. Show seconds and forward counts on messages, use an edit icon or exact view counts, or hide the standard greeting sticker. The same menu also exposes the client’s options for recent stickers, wider messages, bubble rounding and the Telegram compose AI button; it does not turn off Telega AI Chat.
- **Chat list and appearance:** hide the sidebar status badge or the Windows sender thumbnails, and hide All Chats in the vertical or horizontal folder strip when custom folders are available. Hiding that tab does not delete or change any filter on Telegram. Appearance also exposes the native font picker, sticker scale, and sticker timestamp display. Restart for sticker size changes.
- **Message controls:** use the theme accent for sender names, hide inline reactions independently for private chats, groups and channels, count characters as you type, and quote eligible messages automatically when replying without a manual selection. Send As can move to the chat menu. The bottom button for read-only broadcast channels can open a linked discussion or be hidden; channels without a discussion fall back to mute and unmute. Selecting service messages applies only to messages the account can delete.
- **Media and network:** use a custom inline bot for GIF searches and pause voice messages and round video messages independently when the app loses focus. GIF search queries go to the selected bot. Download and upload modes adjust request concurrency and buffering. Faster modes may use more memory and are off by default. Restart to switch modes.
- **Channel feed:** open it from the main menu. Choose visible channels and whether to include the archive, or create local categories. Each account has its own selection. The feed requests up to ten recent posts from each of up to thirty channels per refresh. Activate a preview with Enter or a double click to view the complete post in its normal chat. Marking the current category as read asks for confirmation.
- **Quick actions and polls:** choose and reorder the message hover actions; each action still uses the native eligibility rules. Poll previews only show results the client has already received and is allowed to display.
- **Transcription:** voice and round-video transcription are separate opt-in settings. The menu asks before sending a downloaded, eligible recording of up to 8 MiB to Gemini. A round video sends the whole MP4, including its picture and audio. No protected or disappearing messages are sent; the transcript is not added to Gemini chat history.
- **Message menu and calculator:** show an online badge next to sender avatars when Telegram supplies online status. The context menu can hide Copy Photo and local media saving and show selectable message details. Repeat Message resends an eligible message in the same chat or topic without the original sender attribution; it does not override forwarding restrictions or send a paid message. With the compose calculator enabled, type a line like `(2 + 3) * 4=` and press Space to insert `20` without sending the draft.
- **Privacy controls:** optionally leave chats unread when browsing or sending, suppress story view receipts, or stop this client from announcing its online status. Manual mark-as-read and activity on other devices are unchanged. The profile can show authors of already loaded messages, not a hidden member roster. Viewing content can still produce other signals, so these options do not provide anonymity.
- **Updates:** choose whether to download updates only or download and install them when restarting Telega. This page also opens the project's GitHub release notes.
- **Bundled Tg Ws Proxy:** Windows users can set its local port, buffer, connection pool, logging, data-center routes, Cloudflare fallback, HTTP/2 and secure transport under Network. Changes apply on restart and preserve the proxy secret and unknown options. The bundled process still listens only on loopback. Changing its port does not change any saved connection in Telega.

## Scope of the exDesktop port

The settings use Telega's macOS style, not exDesktop's Material 3 skin. Appearance includes system emoji, Telega icon colors, adjustable avatar corners and an option to ignore peer-specific chat themes. Plugins, support and donations, and streamer mode are excluded; deleted and edited message history is deferred. Telega does not use the donor's badge backend, emulate Telegram Premium, or bypass hidden-member restrictions. The bundled proxy does not expose the donor's fake-TLS setting. The channel feed shows previews rather than embedding full interactive chat bubbles.
