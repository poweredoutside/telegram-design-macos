Telega Desktop — Windows x64

Неофициальный клиент Telegram с оформлением macOS.
Установите приложение в отдельную папку, предложенную установщиком.
При первом запуске войдите в свой аккаунт Telegram.

Масштаб: Настройки → Оформление → Масштаб интерфейса.
Liquid Glass: Настройки → Оформление → Liquid Glass.

Данные аккаунта хранятся в папке TelegramForcePortable рядом с Telegram.exe.
Установщик создаёт пустую папку; чужих аккаунтов в комплекте нет.
При удалении приложения данные аккаунта сохраняются в этой папке.
Для полного удаления сначала выйдите из аккаунта в приложении, затем
удалите оставшуюся папку TelegramForcePortable вручную.
Автообновления для этой сборки поступают только из GitHub Releases проекта
poweredoutside/telegram-design-macos и требуют подписи проекта.
Галочка Tg Ws Proxy запускает локальный прокси вместе с Telega Desktop.
Для первого подключения выберите «Открыть в Telegram» в меню прокси
и подтвердите подключение. Установщик не меняет ваши настройки прокси.

Unofficial Telegram client with a macOS-inspired interface.
Install into the separate folder suggested by Setup. Sign in to your
Telegram account when you first launch the app.
Account data is stored in TelegramForcePortable beside Telegram.exe.
Setup contains no account data. Uninstall preserves your account folder.
To remove all data, log out first and delete the remaining folder manually.
Only signed releases from poweredoutside/telegram-design-macos can update
this build automatically. The Tg Ws Proxy option starts a local proxy with
Telega Desktop. Use the proxy tray menu to connect on first use, then confirm in
Telega Desktop. Setup does not change your proxy settings.
